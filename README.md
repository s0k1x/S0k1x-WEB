# S0k1x-WEB

Portfolio de **s0k1x**, hecho con el sistema de s0k1x-estilo. HTML, CSS y JS sin dependencias, publicado en GitHub Pages.

## Secciones
1. **Portada**: titular y una ventana con pestañas que enseña cuatro proyectos.
2. **Proyectos destacados**: s0k1x-skill, INNRA3D, AUREVIX OS y Reventa.Malaga.
3. **Más proyectos**: SOKIX Toolkit, Aurevix Web y Unuvia, más las herramientas con las que trabajo.
4. **Cierre**: enlace a GitHub.

## Editar
- Los proyectos están escritos en `index.html`.
- Las capturas están en `assets/proyectos/` (ver `LEEME.md`).
- Los colores son las variables `--p-*` del bloque `:root` de `index.html`.
- El contacto apunta a GitHub. Cuando tengas email, cambia los tres botones "Ver mi GitHub" por `mailto:`.
